# Chinese Open Wordnet snapshot

This directory contains the Chinese Open Wordnet 0.9 lemma table used to
attach Chinese lemmas to Princeton WordNet 3.0 senses by exact synset ID.

- Upstream project: <https://bond-lab.github.io/cow/>
- Upstream repository: <https://github.com/bond-lab/cow>
- Upstream commit: `6f6451bafab7a49b73bace47697a720c619abef4`
- Imported file: `docs/data/0.9/wn-data-cmn.tab`
- Local filename: `wn-data-cmn.tab`
- SHA-1: `b621d7787184df55555eb597edc85c4c64a812c3`

The local snapshot contains the same non-empty rows as the upstream file;
only its text encoding and Windows line endings were normalized during import.

`curated-translations.json` contains narrowly scoped replacements for
high-confidence source errors found during review. Each replacement is keyed
by the same WordNet 3.0 synset ID and records the reason for the change.
