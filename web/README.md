# GRE 3000 Vocabulary Trainer PWA

适配 iPhone、iPad 和桌面浏览器的 GRE 3000 可安装网页应用。

- 四种学习模式与 0～3 星标注；
- 首页独立的长难句阅读入口：131 句、一页一句、逐词点查；
- 原书 List 顺序、等价词、词根词和近形异义词；
- Service Worker 离线缓存；
- JSON 进度文件与 Windows 桌面版双向导入/导出；
- 无需账号的同步码自动云同步；
- AES-256-GCM 设备端加密；D1 不保存明文进度，只保存加密进度及同步所需的技术元数据。

## 长难句阅读

首页的“杨鹏 GRE 阅读长难句”入口同时适配桌面浏览器和手机：

- 共 131 句，每页显示一句，并保留原书编号。原书缺少第 70 句，因此界面会从第 69 句直接切换到第 71 句。
- 每个英文单词均可点击，优先复用内置点词词典查看中文总览、逐义项中文、WordNet 英文义项、例句和已收录词组；少量未收录的专名、所有格或复合词仍会打开查询窗口，可主动联网翻译。选中句子或词组后也可翻译。
- 桌面端支持 `←` / `→`，手机端支持左右滑动，也可使用上一句、下一句按钮。
- 首次在线加载完成并由 Service Worker 缓存后，长难句与内置点词查询可离线使用；联网翻译仍需网络。

```powershell
npm install
npm run dev
npm test
```

词库数据由仓库根目录的 `scripts/export_web_data.py` 从已审核 SQLite 数据库生成。
